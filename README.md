# 💳 Credit Card Financial Dashboard

An interactive **Power BI dashboard** developed to analyze credit card customer and transaction data and track key financial performance metrics.

### 🛠️ Tools & Technologies

**SQL | Power BI | DAX | Data Analysis | Data Visualization**

### 📌 Project Highlights

* Imported and analyzed customer and transaction data using **SQL**.
* Built an interactive **Power BI dashboard** to monitor revenue, transactions, customers, and key KPIs.
* Created **DAX measures** for revenue, weekly performance, age groups, income groups, and other business metrics.
* Analyzed **weekly and year-to-date performance** to identify trends and business insights.
* Tracked metrics including **revenue, transaction amount, transaction count, interest, activation rate, and delinquency rate**.
* Generated actionable insights based on customer demographics, card types, and geographic performance.

### 📊 Key Insights

* **Overall Revenue:** 57M
* **Total Transaction Amount:** 46M
* **Total Interest:** 8M
* **Activation Rate:** 57.5%
* **Delinquent Rate:** 6.06%
* **Week-over-Week Revenue Growth:** 28.8%

### 🎯 Objective

To transform credit card customer and transaction data into an interactive dashboard that enables **performance monitoring, trend analysis, and data-driven decision making**.
